# Synthetic dataset

## Source and license

This project uses a dataset generated by code in this repository. It contains
no real people, companies, orders, or business outcomes. The generator and its
output are covered by the repository's license once one is selected.

The default seed (`42`) produces:

- 2,000 customers
- 500 products
- 10,000 orders
- one to four order items per order
- one payment record per order
- twelve monthly files each for orders, order items, and payments

The exact row count and status distribution are written to `manifest.json`.

## Why synthetic data

Synthetic data avoids unclear third-party licensing and personally identifiable
information while preserving the relationships needed to learn ETL concepts.
The fixed seed makes tests and interview demonstrations repeatable.

## Known limitations

- Prices do not model discounts, tax, shipping, or currency conversion.
- Each order has exactly one payment record.
- Customer and product changes are snapshots rather than change-data-capture
  events.
- Distributions are plausible test inputs, not evidence about a real business.
